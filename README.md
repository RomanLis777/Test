git init — Создать новый репозиторий в текущей папке.

git clone <url> — Склонировать репозиторий из удаленного хранилища (например, с GitHub).

Основной рабочий цикл
git status — Показать состояние файлов (изменены, но не добавлены, добавлены в коммит и т.д.).

git add <файл> — Добавить конкретный файл в индекс (подготовить к коммиту).

git add . — Добавить все измененные и новые файлы в индекс.

git commit -m "сообщение" — Зафиксировать изменения в репозитории с комментарием.

git commit -am "сообщение" — Сразу добавить в индекс и закоммитить изменения в уже отслеживаемых файлах (комбинация add и commit для упрощения).

Просмотр истории и изменений
git log — Показать историю коммитов.

git log --oneline — Показать компактную историю в одну строку на коммит.

git diff — Показать незакоммиченные изменения в файлах.

git diff <файл> — Показать изменения в конкретном файле.

Работа с ветками
git branch — Показать список всех веток (текущая будет выделена).

git branch <имя_ветки> — Создать новую ветку.

git checkout <имя_ветки> — Переключиться на другую ветку.

git switch <имя_ветки> — Более современная команда для переключения ветки.

git checkout -b <имя_ветки> — Создать новую ветку и сразу переключиться на нее.

git merge <имя_ветки> — Влить указанную ветку в текущую.

git branch -d <имя_ветки> — Удалить ветку (безопасно, если изменения слиты).

Работа с удаленным репозиторием
git remote -v — Показать список подключенных удаленных репозиториев.

git push origin <ветка> — Отправить локальные коммиты в удаленный репозиторий (например, в ветку main или master).

git pull — Скачать изменения из удаленного репозитория и автоматически слить их с вашей текущей веткой.

git fetch — Только скачать изменения из удаленного репозитория, но не сливать их.

Отмена изменений
git restore <файл> — Отменить изменения в файле (еще не добавленные в индекс).

git restore --staged <файл> — Убрать файл из индекса (перевести обратно в "не добавленные").
